# High Branding Innovations Ltd

> *"Where Identity Meets Impression"*

High Branding Innovations Ltd is a branding and premium corporate gifts company based in Lagos, Nigeria. We combine strategic corporate brand identity design with the sourcing, customization, and supply of premium corporate gifts — giving our clients a single trusted partner for both how their brand looks and how it is felt.

---

## 🏛️ Core Capabilities

1. **Brand Identity Design**: Logo design, visual identity systems, enterprise brand guidelines, and brand strategy consulting.
2. **Premium Corporate Gifts**: Curated executive hampers, debossed Italian leather goods, precision laser-engraved writing instruments, and bespoke presentation packaging.
3. **Bundled Brand + Gift Packages**: Combined identity systems and branded welcome/launch kits for turnkey unboxing.
4. **Event & Exhibition Branding**: Large-scale conference, AGM, summit collateral, and VIP delegate suites.

---

## 🎨 Design System

- **Aesthetic**: Minimalist editorial luxury, warm white & porcelain base (`#FFFFFF`, `#FAFAF7`) with regal midnight navy accents (`#0B1528`) and brushed champagne gold hairline borders (`#C5A059`).
- **Typography**: Editorial serif (*Cormorant Garamond*) paired with Swiss-style sans (*Inter*).
- **Stack**: React 18, Vite, Tailwind CSS, Lucide Icons.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/samuelmohel/High-Branding.git
cd High-Branding
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
